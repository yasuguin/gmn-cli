# gemini-api-cli-plus

Unofficial fork of google-gemini/gemini-api-cli. Not affiliated with Google.

`gemini-api-plus` is the fork's CLI. It is installed side by side with the official `gemini-api` command and does not replace it.

## Usage

```sh
uvx gemini-api-cli-plus --version
uv tool install gemini-api-cli-plus
uvx --from gemini-api-cli-plus gemini-api-plus --version
```

Each OS and CPU architecture gets its own wheel that contains the native binary, so no Go toolchain or Python runtime dependency is needed beyond Python itself.

Source and issues: https://github.com/yasuguin/gemini-api-cli-plus
